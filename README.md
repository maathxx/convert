# 💱 Convert

Projeto para conversão de moedas desenvolvido em JavaScript puro.

## 📖 Sobre

Aplicação web simples que permite converter valores entre diferentes moedas, praticando manipulação do DOM, lógica de conversão e integração com dados em JavaScript.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## 💻 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/maathxx/convert.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd convert
   ```
3. Abra o arquivo `index.html` no navegador.
